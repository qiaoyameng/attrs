Fields gained a *positional_only* option: `attrs.field(positional_only=True)` (and `attr.ib(positional_only=True)`) places the generated `__init__` parameter before a real `/` separator, so it can only be passed positionally. Invalid combinations with regular and *kw_only* fields (including inheritance and default ordering) raise a `ValueError` at class creation time, while `attrs.evolve()`, `__replace__`, `__match_args__`, and `inspect.signature` stay consistent.
